# DevPals News 📰

DevPals News is a modern and dynamic web application built to deliver real-time news updates. Powered by a live News API, it allows users to browse and filter breaking news across various categories seamlessly.

## ✨ Features
- **Real-Time News Fetching:** Integrates with a live News API to display up-to-date headlines and articles.
- **Category-Based Filtering:** Easily switch between different news topics (such as Technology, Business, Sports, Finance, etc.) to view relevant content.
- **Responsive Design:** Clean and modern UI optimized for seamless viewing across desktops, tablets, and mobile devices.
- **Interactive UI:** Smooth user experience with quick loading states and organized layouts.

---

## 🛠️ Tech Stack
- **HTML5** & **CSS3** (For structuring and styling the layout)
- **JavaScript (ES6+)** (For DOM manipulation, API fetching, and dynamic rendering)
- **News API** (For fetching real-time global news data)
